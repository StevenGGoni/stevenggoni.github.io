Librerías

Aquí se enlistan todas las librerías que se van a utilizar durante la resolución de estos ejercicios.

Recuerde que, de no tenerlos instalado, debe hacerlo.

library(BSDA)

Potencia estadística

Para el primer ejemplo desarrollado en clase sobre este tema, se puede obtener de esta manera, con R Base.

Recuerde redondear hacia arriba

power.t.test(n = NULL, # ausente, se va a estimar
             delta = 0.01, # tamaño del efecto
             sd = 0.0035,
             power = 0.85, # potencia
             sig.level = 0.01, # alpha
             type = "two.sample", # tipo de t.test
             alternative = "two.sided") # tipo de H1

     Two-sample t test power calculation 

              n = 5.105705
          delta = 0.01
             sd = 0.0035
      sig.level = 0.01
          power = 0.85
    alternative = two.sided

NOTE: n is number in *each* group

Se requieren 6 muestras para cada instrumento de medición, es decir, 12 en total.

A continuación se muestra un forma de obtener el tamaño de muestra vía potencia estadística para cada una de las pruebas de hipótesis que se estudian en el curso.

Todos los casos desarrollados son hipotéticos, no están ligados a un ejemplo o contexto.

Para una media

             type = "one.sample", # tipo de t.test

Para una proporción

power.prop.test(n = NULL, 
                p1 = 0.6,         # Expected proportion
                p2 = 0.5,         # Null hypothesis proportion
                power = 0.8,      # Desired power
                sig.level = 0.05, # Significance level
                alternative = "two.sided")

     Two-sample comparison of proportions power calculation 

              n = 387.3385
             p1 = 0.6
             p2 = 0.5
      sig.level = 0.05
          power = 0.8
    alternative = two.sided

NOTE: n is number in *each* group

Aunque power.prop.test() se diseñó principalmente para comparar dos proporciones, puedes simular una prueba de una proporción comparando una proporción esperada (p1) contra una proporción de referencia (p2) como si fueran dos “grupos”, donde uno representa la hipótesis nula.

Tome en cuenta que el resultado obtenido es para UNA proporción. Solo hay un grupo.

Para dos proporciones

power.prop.test(n = NULL, 
                p1 = 0.4,         # Proportion in group 1
                p2 = 0.6,         # Proportion in group 2
                power = 0.8,      # Desired power
                sig.level = 0.05, # Alpha level
                alternative = "two.sided")

     Two-sample comparison of proportions power calculation 

              n = 96.92364
             p1 = 0.4
             p2 = 0.6
      sig.level = 0.05
          power = 0.8
    alternative = two.sided
