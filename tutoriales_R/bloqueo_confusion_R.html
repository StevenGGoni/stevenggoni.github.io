Diseño factorial completo \(2^{5}\) en \(2^{1}\) bloques en R

Fecha de publicación

20 de octubre de 2026

Librerías

library(tidyverse)
library(FrF2)
library(broom)
library(flextable)

Introducción

Para realizar un diseño factorial completo \(2^5\) (32 combinaciones) dispuesto en bloques, podemos utilizar la interacción de mayor orden (\(ABCDE\)) como contraste definidor de bloqueo.

Al confundir \(ABCDE\) con los bloques, sacrificamos la estimación de esta interacción de 5 factores a cambio de aislar la variabilidad por bloques. En este ejemplo, replicamos el experimento 2 veces (\(N = 64\) corridas) distribuidas en 4 bloques de tamaño 16.

A <- B <- C <- D <- E <- c(-1, 1)

# Base completa 2^5
diseno_base <- tidyr::expand_grid(A, B, C, D, E)

# Experimento replicado con confusión de ABCDE
diseno <- diseno_base |> 
  rbind(diseno_base) |> 
  dplyr::mutate(ABCDE = A*B*C*D*E) |> 
  dplyr::arrange(ABCDE) |> 
  dplyr::mutate(Bloque = factor(c(rep(1, 16), 
                                  rep(3, 16), 
                                  rep(2, 16), 
                                  rep(4, 16)))) |> 
  dplyr::select(-ABCDE) # Se elimina el contraste tras asignar bloques

Análisis del modelo

Trabajemos con el diseño creado con R base, agreguemos una respuesta ficticia, solo a modo de ejemplo.

R <- rnorm(64, 30, 2)

resultados <- cbind(diseno, R)

Ajustamos el modelo saturado. Al estar Bloque definido como factor (3 GL), se absorbe la variación correspondiente a \(ABCDE\), por lo que la interacción A:B:C:D:E resulta inestimable (aparece como NA / 0 GL), demostrando la confusión deseada.

modelo1 <- lm(R ~ Bloque + A*B*C*D*E, 
              data = resultados)

broom::tidy(modelo1) |> 
  dplyr::mutate(across(where(is.numeric), ~ round(., 2))) |>

¿Qué nos falta?

Pues eliminar todo aquello que no aporte al modelo, esta es una forma de hacerlo automático, pero en DdE puede ser más valioso hacerlo paso a paso.

#forzando que el bloque siempre sea parte del modelo
modelo_final <- step(modelo1, 
                     direction = "backward", 
                     scope = list(lower = ~ Bloque, 
                                  upper = formula(modelo1)), 
                     trace = 0)
