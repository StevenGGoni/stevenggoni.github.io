26 de septiembre de 2026

Librerías

Al inicio de todas las clase se colocarán las librerías que se van a utilizar para el desarrollo de los casos.

library(tidyverse)
library(FrF2)
library(broom)
library(flextable)

Introducción

Un diseño factorial fraccionado de dos niveles permite estudiar muchos factores con un número reducido de corridas experimentales. En lugar de ejecutar todas las combinaciones (\(2^k\)), se toma una fracción que mantiene propiedades de ortogonalidad y resolución.

Diseño

Vamos a diseñar el mismo experimento de la presentación

\(2^{6-3}_{III}\)

diseno <- FrF2::FrF2(nfactors = 6, nruns = 8, 
                     generators = c("AB", "AC", "BC"), 
                     randomize = FALSE)

Para un gráfico de Pareto

efectos <- coef(modelo1)[-1]  # quitamos intercepto
df_efectos <- data.frame(
  factor = names(efectos),
  efecto = abs(efectos)) %>% 
  tidyr::drop_na()

ggplot(df_efectos, aes(x = reorder(factor, efecto), y = efecto)) +
  geom_bar(stat = "identity", fill =  "darksalmon") +
  coord_flip() +
  labs(x = "Factor/Interacción", y = "Magnitud del efecto",
       title = "Pareto de efectos factoriales") +
  theme_bw()
